# Product Overview

Vireo is a turnkey Electronic Thesis and Dissertation (ETD) Management System developed by the Texas Digital Library. Starting with version 4.x, Vireo offers fully customizable workflows and controlled vocabularies for managing academic submissions.

## Core Functionality

- ETD submission and management workflow
- Customizable submission workflows and controlled vocabularies
- Multi-organizational support with hierarchical organization structures
- Document upload and management with configurable file types
- Email notification system with template-based workflows
- Export and packaging for various repository formats (DSpace, ProQuest, MARC21)
- SWORD protocol support for repository deposits
- User role management (Student, Reviewer, Manager, Administrator)
- Embargo management for delayed publication

## Key Features

- Configurable workflow steps per organization
- Field-level validation and customization
- Batch operations for submission management
- Advanced filtering and search capabilities
- Integration with external systems via SWORD protocol
- Support for multiple database backends (H2, PostgreSQL, MySQL)
